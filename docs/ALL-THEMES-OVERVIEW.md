## 🚀 How to Switch Themes

### Quick Switch (Header)
1. Click profile avatar (top right)
2. See all 5 theme icons
3. Click any theme icon
4. Instant transformation! ✨

### Full Preview (Sidebar)
1. Click user profile (bottom left)
2. Scroll to "Choose Your Theme"
3. See full preview cards
4. Click any theme card
5. Watch it transform! 🎨

### Keyboard Shortcut (Coming Soon)
- `Ctrl/Cmd + Shift + T` - Open theme selector
- `1-5` - Select theme number
- `Enter` - Apply theme
