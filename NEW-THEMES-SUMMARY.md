## 🚀 How to Use

### Switch Themes Instantly

**Method 1: Header (Quick Switch)**
1. Click your profile avatar (top right)
2. See all 5 theme icons
3. Click any icon - instant change! ✨

**Method 2: Sidebar (Full Preview)**
1. Click user profile (bottom sidebar)
2. Scroll to "Choose Your Theme"
3. See beautiful preview cards
4. Click any theme - watch the transformation! 🎨

### Programmatic Usage
```typescript
import { useTheme } from 'next-themes'

function MyComponent() {
  const { setTheme } = useTheme()
  
  // Switch to sunset
  setTheme('sunset')
  
  // Switch to forest
  setTheme('forest')
}
```
